# 📊 Risk Calculator – Excel Project

An Excel-based **risk assessment and decision-support tool** that uses weighted scoring to evaluate financial risk and classify risk levels.

## 🎯 What It Does

- Analyzes **Credit Score, Income, Debt, Savings & Late Payments**
- Uses **data normalization and weighted scoring**
- Classifies users into **Low, Medium & High Risk**
- Provides **Real Estate Risk Mitigation Strategies**
- Supports **data-driven decision-making**

## 🛠️ Tools & Skills

**Microsoft Excel | Data Analysis | Risk Modeling | Excel Formulas | Weighted Scoring | Decision Making**

## 💡 Key Takeaway

Built a practical Excel model to convert financial and real-estate risk data into **clear, actionable insights**.
